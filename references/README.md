# Supplied references

- `annotated-spatial-reference.png`: authoritative spatial reference. Yellow identifies the existing Dunkin building; red marks the approximate waiting area. These circles are instructions and never render in the game.
- `nj-transit-visual-reference.png`: photographic reference for coach appearance and boarding atmosphere only. The game route is **163**, independent of the number visible in this photograph.

These originals are preserved for future editing. They are outside `public/` and are not shipped or cached by the PWA. The clean original map and logo remain in `public/assets/`.
